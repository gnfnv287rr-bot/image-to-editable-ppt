# 可复用模板与已有 PPT 版式整理

## 可复用模板的取舍

仅在用户明确要模板、允许优化结构时使用这些设计判断；还原截图时仍以参考为准。

- 同类页共用标题锚点、主内容边界和字体层级，按长标题、较长标签、单位和替换图片检查容纳空间。统一的是语法，不是把所有页面做成同一布局。
- 背景保留品牌或主题气质，让阅读区对比稳定；必要时以适量留白或内容底板分开文字和背景，不为统一而全页加卡片。
- 英文角标、手写旁白、页码等辅助元素只在有导航或表达作用时使用；新增模板可减少无功能装饰。艺术字仍可独立成素材，普通文字保持原生；不要自动将手写字体全部改成普通字体。
- 结论、分类和数据的顺序由信息关系决定。例如解释三类方向的数据页可用“结论 → 方向 → 数据证据”，不是所有页面都套用此顺序。
- 照片与数据留出独立替换空间，同时保留必要的景观连贯性。留白是为使用服务，不默认缩小所有照片。
- 跨页复用经过检查的底图、图标和艺术素材；只处理新增或确有问题的素材，不反复生成同一雪景等共用视觉。

## 已有 PPT：只整理版式

以最新 PPTX 为内容基线。源截图或旧交付只用于理解风格，不把用户已修改的内容回滚。

1. 查看整套实际渲染，找出影响阅读的具体问题。以保留设计为目标，优先修正标题基线、正文左边界、列中心、数字与单位关系、行距、分隔线和图片边距；已经合适的页面可以不改。
2. 将用户的“不要增减”落实到页数、顺序、文案、数据、素材和内容对象。空白模板页、占位文字、无数据的一列、辅助装饰不自动删补。发现文案或章节标签疑似有误，单独说明，未经授权不改。
3. 可调整对象位置、大小、字号、间距和必要的换行；尽量保留现有字体、颜色、分组和图片裁切。仅为了对齐而解组时，应恢复合理的对象关系，不降低可编辑性。
4. 在原 PPT 上做局部编辑，避免从渲染图整页重建，也避免整个文件重导出导致主题、备注、图片或组合结构丢失。处理嵌套分组时换算父级坐标与缩放，不能把页面坐标直接写入子对象。
5. 不因普通对齐任务重新生图、下载字体或重做素材清洁。原有素材若疑似有残影，指出问题；只有本次确实修改或重建该素材才对其执行完整原图与底层清洁验收。

## 交付验证

- 保留原文件，另存修改版。记录原文件哈希，并在结束时确认未被改写。
- 比较修改前后的页数、顺序、可见文案和数值；严格“不增减”时同时检查对象保留和媒体资源。文本 XML 分段改变不等于文案改变，应核对实际文本；不能只比较总对象数来证明所有内容都保留。
- 检查文件包完整性，实际渲染修改版并逐页看对齐、遮挡、字体、换行和图片。已有的画布外空对象或出血图像不能一概当成错误；确认其来源及实际显示后再决定是否修正。
- 原生文本、形状和图片对象应继续可编辑或可替换。仅在当前环境确实验证时说明 PowerPoint/WPS 实机效果。
- 简短交付成品和预览，说明本次调整与保留范围。不要为普通整理任务额外导出长日志或素材包。
