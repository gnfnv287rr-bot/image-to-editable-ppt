# 批量还原的视觉校准

适用于首次制作一套截图、沿用新制作方法批量展开，或返修已被用户否定的成品。目标是尽早暴露共性偏差，保留原稿设计与可编辑性；不自动增加用户审批步骤，也不把一次案例的页数、颜色或还原率写成固定规则。

## 锁定基线

- 明确当前源文件、参考图、认可样张和正在修改的成品分别是哪一版。参考图中的待补信息、合作免责声明与业务数字照原意保留；OCR纠错只恢复可辨认原文，不顺手修改策略、价格或事实。
- 多页且有原稿时，维护简短页序映射：`输出页 / 源文件页或图片ID / 页面标题或主题 / 保留、替代、新增等状态 / 对应依据`。可用原稿媒体、页面缩略图和标题交叉核对，不为核对顺序重新设计页面。
- 检查总页数与唯一对应关系。重复图、旧版与新版并存、图像相似但文案不同，须按当前授权和可见证据判断；仅凭相似度不能决定删除、替换或合并。依据不足且影响交付时再向用户澄清。

## 代表页怎么选、看什么

优先覆盖实际难点，避免只校准简单封面或纯文字页。通常少量页面即可覆盖多类问题，同一页可以兼任多项。

| 难点 | 校准重点 |
| --- | --- |
| 大标题、章节页 | 字形气质、粗细、字面大小、行距、行长、对齐及留白；不只是字号接近 |
| 照片或纹理叠字 | 人物/产品占比、主体裁切、无字修复区域、文字对比度与图层次序 |
| 密集表格、预算、数字 | 列宽、行高、数字与单位分离、编号与标题各自字号、金额和总数无误 |
| 流程与关系图 | 节点大小、连接方向、弧线、箭头形状、阅读路径和视觉重心 |
| 图标、真实UI、案例截图 | 图标轮廓及透明边缘、截图清晰度、合法截图文字与外部正文的边界 |

对照时使用同一画布比例和接近的显示尺寸，分别检查整页构图、关键局部、移除文字后的素材。发现“结构都有，但看着不像”，先检查字体比例、图片占比、层次和留白，不先换一套通用模板。

## 从代表页展开

- 把校准后的字体选择与字面测量方法、图形样式、素材边界和导出参数用于对应页面类型；仍按每页参考调整，不把一页的数值机械套遍整套。
- 缓存已清理的素材；从高清原件提取，避免先缩成预览图再裁切反复压缩。像素尺寸、实际插入尺寸与目标观看方式一起决定清晰度，插值放大不等于找回原始细节。
- 对照片、民族纹样、复杂光影和笔刷边缘，不以少量纯色形状替代其视觉层次。能提取就提取；文字遮挡处确需修复时限制修复范围，保护人物、产品与真实截图，并说明局部差异。
- 图标在原稿无矩形底时，使用干净透明素材、矢量或适合的原生图形；不能用带底截图再加同色矩形假装透明。原稿本就有底色的图标保留其设计。
- 不把正文连同照片一起保留，再叠一层可编辑字。照片中混入标点、半个字、标签、分隔线、旁边图标等也算边界问题，不能因为正文大部分清掉就放行。

## 常见的自动识别陷阱

详细实现检查见 [pptx-production.md](pptx-production.md) 中的“OCR与文字适配”。

- “01＋标题”“金额＋单位”可能被OCR识别为同一块，但原稿字号不同，要拆开处理。
- 红色项目符号配灰色正文、金白混排、深底浅字，不能只依据少数最深/最亮像素决定整行的颜色和字面范围。
- 近似宋体名称、声明粗体、文字框刚好容纳，都不证明实际字形接近原图；最终渲染才是判断依据。

## 返修与验收

用户指出质量问题后，把可观察缺陷与原因分开记录。例如“图标带方底”是缺陷，来自裁图边界还是透明度处理要检查素材后再判断。优先修共同原因，再检查代表页与受影响页；不要对整套盲目重跑同一失败方法。

完整交付前，检查所有页面的实际渲染和嵌入原图，再检查底层副本。人物、包装和截图内部合法文字可以保留；普通标题/正文残影必须清理。工具输出的对象数、ZIP通过和几何检查只支持相应结构结论。

保留一份简短内部修订记录即可：`版本 / 改动范围 / 核验范围 / 已知限制`。用户说“之前那版”时用它定位，不把最近一次小改动误当成用户所指的整轮质量变化。
