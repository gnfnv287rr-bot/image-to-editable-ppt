# 图转可编辑PPT

**把参考图还原成能改字、换图、拆分复用的 PPT，同时保留原设计的气质。**

适合把已有提案页、图片型幻灯片、封面、章节页和设计参考转成可继续制作的 PPT，也支持可复用模板制作与已有可编辑 PPT 的局部版式整理。名称是「图转可编辑PPT」，调用名是 `$image-to-editable-ppt`。

## 三种使用方式

- **截图还原**：忠实保留构图、文案和字体气质，分别重建可编辑文字、基础图形和干净素材。
- **可复用模板**：保留设计主题，为后续替换文字、数据和图片留出空间；不把每页统一成固定卡片墙。
- **已有 PPT 版式整理**：以用户最新修改版为基线，只调整对齐、间距和层级，保留页面、原文、素材与占位；不重新拆图或生图。

## 本次同步的优化

- 批量制作先用代表页校准字体比例、图片边界和层次，再检查全部页面，避免把同类问题复制到整套。
- 核对原稿与输出页的对应关系，保留已认可页面；页数、页序和预览对应同一份最终文件。
- 加强图标透明边缘、素材残字、分隔线污染、图片有效分辨率与文字适配检查。
- 图片优先复用高清原件；插值放大不等于恢复细节，照片仍按位图说明编辑边界。
- 页码按用户要求处理，保留章节号、步骤号、金额及其他业务数字。

## 核心差异

比较图转 PPT 方案时，应同时看整体还原和拆分后的素材质量。下面比较的是处理方式，不代表所有市场工具都只有某一种能力。

| 比较点 | 仅把整图放入 PPT | 仅 OCR 后叠加文字 | 图转可编辑PPT 的制作标准 |
| --- | --- | --- | --- |
| 改字与换图 | 整页作为一张图片 | 新文字可修改，底图可能仍含原文 | 正文重建为文字框，图片和图形分别成对象 |
| 图片是否干净 | 原文与图片在一起 | 若未清理底图，移动文字后会露出旧字 | 检查完整嵌入原图和底层画面，清除误混入的字影与版式残片 |
| 原设计的字体气质 | 保留视觉，但无法直接改字 | 单靠文字识别不能保留所有艺术字形 | 常规文字可编辑，特殊标题保留为独立透明素材或矢量轮廓 |
| 素材能否复用 | 一般只能整页使用 | 取决于额外拆分工作 | 按佛像、山景、前景、标题等语义边界拆分，便于单独使用 |
| 缺少真实截图 | 依赖输入截图 | 依赖输入截图 | 真实 UI、账号和案例优先复用；需要用户补充的部分留占位 |
| 交付检查 | 整页画面 | 整页画面与识别文字 | 整页渲染、完整原图、底层无字画面及文件结构一起检查 |

最关键的验收动作是：**把文字移开后，图片里仍不应出现旧文字。** 单纯“能选中多个对象”不能证明拆分已经完成。

## 使用方法

上传参考图后，直接发送：

> 使用 $image-to-editable-ppt，把这些图转成可编辑 PPT。尽量保留原配色、布局和字体气质，文字可改、图片可换，独立素材里不能残留原文字影；交付 PPTX、预览图和拆分素材。

如果有需要自己补的真实截图，加上：

> 平台截图和数据截图由我补充，请保留对应占位，不生成替代截图。插画、背景或被文字遮住的艺术素材，可以按需修复。

如果是封面或章节页的特殊字体，加上：

> 花式标题优先保留原字形，做成独立素材；正文保持可编辑，不需要为这一页增加字体库。

已有可编辑 PPT 只需整理时，可直接发送：

> 使用 $image-to-editable-ppt 整理这份 PPT，只调整对齐、间距和文字层级，保留全部页面、原文及素材，不增减内容，另存修改版并附预览。

同时提供原始 PPT、高清图片或文字稿，可提高素材质量和文案准确性。只有低清截图也可以开始，但照片细节和被遮挡区域无法保证与原件完全相同。

## 可编辑范围

- **可以直接改**：常规文字、数字、标签、线条、色块、箭头和适合原生重建的简单图表/流程。
- **可以移动、替换和复用**：照片、插画、纹理、复杂艺术标题等独立素材。照片内部不会自动变成可编辑的矢量笔画。
- **需要补充**：尚未提供的真实账号、平台界面、数据证据和客户截图。占位会记录对应位置及用途。

## 交付与效率

截图还原默认交付可编辑 PPTX、整页预览、独立素材和底层无字检查图，并说明特殊标题、位图素材和待补截图的边界。已有 PPT 版式整理默认只交付修改版 PPTX 与预览。

制作时优先复用已有素材，只生成或修复确实缺失、受污染的局部；仅在参考本身重复使用时跨页复用对应素材，减少重复生成，同时保留各页构图。复杂页仍可能需要更多时间，不承诺所有页面都达到同一还原率或固定分钟数。

底部山景这类曾与正文混在一起的素材，会检查并清理后再独立交付。需要重建的区域可能与原图略有差异，这些差异会明确说明。


## 安装

将仓库内容放到 Codex 的 Skill 目录中，目录名为 `image-to-editable-ppt`。例如在尚未安装同名 Skill 的机器上：

```bash
git clone https://github.com/gnfnv287rr-bot/image-to-editable-ppt.git ~/.codex/skills/image-to-editable-ppt
```

也可以下载 Release 中的压缩包，将其中的 `image-to-editable-ppt` 文件夹放到 `~/.codex/skills/`。已有同名目录时，先保留自己的修改再更新。

本 Skill 是代理工作流指令和验收工具，需要支持 Skills 的助手，以及可用的 PPTX 制作、渲染和图像修复能力；它本身不是独立的一键转换程序。

## 检查脚本

脚本依赖 Python、`python-pptx` 和 Pillow。它检查文件结构、提取未裁切的完整嵌入原图，并生成去除文字等对象后的检查副本。它不做 OCR、不渲染幻灯片，也不会自动判定图片中是否存在字影；这些仍需实际看图验收。

```bash
python scripts/inspect_layers.py final.pptx \
  --report qa/layers.json \
  --extract-dir qa/embedded-images \
  --isolation-pptx qa/artwork-only.pptx
```

如果有保留为图片的艺术标题，用 `--exclude-picture-name "对象名"` 从底层检查副本中排除，避免把合法标题素材误当成残影。
